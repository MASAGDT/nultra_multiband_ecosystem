# Contributing

Thanks for the interest.

This repository treats the canonical Version 1.0 baseline as frozen:

- keep `src/nultra_multiband_ecosystem/processor.py` stable unless a change is explicitly meant to become the new baseline
- use forks or branches for experimental DSP ideas
- do not commit source music files or rendered `.wav` outputs

If you want to explore a new idea, prefer:

1. document the hypothesis
2. fork the canonical baseline
3. keep perceptual goals and parameter changes explicit
4. compare against `sweet-spot` and `stronger`
